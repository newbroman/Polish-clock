📱 How to Use

  • Drag the Hands: Move the clock hands to change the time.
  • Manual Entry: Type a time (e.g., 14:20) in the box.
  • EN/PL: Switch the interface and help language.
  • Phon: Toggle the phonetic "sounds-like" guide.
  • Quiz Mode: Test yourself! Pick the correct Polish phrase for the time shown on the clock. The buttons are color-coded: Green for correct, Red for wrong.

👔 Formal Grammar (24h)

Used for official schedules and digital clocks. It is mathematically precise.

Part Number Type Case Example
Hour Ordinal (1st, 2nd...) Nominative (Orange) Godzina siedemnasta
Minute Cardinal (1, 2, 3...) Nominative (Black) dziesięć (17:10)

☕ Casual Grammar (12h)

Used in daily conversation. The hour changes ending based on the word before it.

Word Used Number Type Case Used Example
(On the hour) Ordinal Nominative (Orange) Czwarta (4:00)
Po (Past) Ordinal Genitive (Purple) Pięć po czwartej (4:05)
Wpół do (Half) Ordinal Genitive (Purple) Wpół do piątej (4:30)
Za (To) Ordinal Nominative (Orange) Za pięć piąta (4:55)

*Note: Minutes are always Cardinal numbers in casual mode.
